# 🎮 Simon Game

A browser-based memory game that challenges users to repeat a growing sequence of colors. This is a direct implementation of the classic **Simon** game using HTML, CSS, JavaScript, and JQuery, inspired by the course ["The Complete 2023 Web Development Bootcamp"](https://www.udemy.com/course/the-complete-web-development-bootcamp/learn/lecture/12664354#overview) by Dr. Angela Yu.

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- JQuery

## 🎯 Features

- Pattern-matching logic
- Keyboard-controlled start
- Sound effects and animation for feedback
- Game over and restart functionality

## 🕹️ How to Play

- Press any key to start the game.
- Watch the pattern of lights and sounds.
- Repeat the sequence by clicking the colored buttons in the same order.
- The pattern grows with each level — see how long you can keep up!
